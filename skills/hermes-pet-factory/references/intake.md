# Intake and resumable approvals

Fill known answers first, using only relevant private configuration; never dump `.env` or keys. Ask the missing fields in ONE structured question packet. Suggested answers can be recommended, but require an answer for creative/cost/install choices that matter.

- **Job:** create or update; name/slug; profile's purpose; existing pet/art paths; precise edits and protected original regions/rows; references and their roles.
- **Targets:** exact Hermes box/profile/home(s); desktop/terminal/Relay destinations; exact Relay endpoint/profile identity; keep Portrait initially or select Pet? Discover unambiguous existing mappings, present them for review, and ask about ambiguity. No inferred network endpoint or copied enrollment.
- **Look:** species/character, silhouette and proportions, palette/materials, distinctive fixed markings, outfit/props, demeanor; square/circular portrait composition and backdrop; constraints/avoidances. Default to the established crisp detailed pixel style, but preserve the supplied reference's actual proportions and pixel density.
- **Choreography:** idle; move-right/left (walk, glide, teleport or anatomy-specific alternative); greeting; success/jump; error; signature/waiting; working-in-place; review; listening; three talking amplitude poses; sleeping. Ask which signature, props/effect colors, and when it should play. Humanoid listening defaults to hand-to-ear; adapt naturally for other anatomy. Working and waiting must be visibly different.
- **SOUL:** reuse unchanged, propose a narrow update, or author a new one; core role, temperament, language, humor/formality, values and boundaries; no invented capabilities.
- **Voice:** existing voice ID or guided shortlist/custom design; language/accent, pitch/timbre, apparent age, energy, pacing and expressiveness; what to avoid; sample script; per-profile server voice default versus explicitly requested Relay BYOK override. Do not infer these solely from a character's appearance.
- **Execution and cost:** native OpenAI image tool available? If not, approved OpenAI API route/key source or T3 handoff? Image job/iteration budget and ElevenLabs design/TTS call+character budget; allowance to save a new voice/library entry. Costs are quoted/approved, not assumed free. No new subscription/purchase.
- **Delivery:** previews only, stage only or approved install after review; permitted profile reloads; current device availability and whether an actual playback/hold-to-talk test is authorized.

One run per pet/revision, with `brief.json`, `generation-ledger.jsonl`, `approvals.json`, `voice/spend.jsonl`, source hashes, previews, a fresh `bundle/`, `SOUL.proposed.md`, `SOUL.diff`, and target receipts. Keep personal art and configuration outside Git/public uploads. A workflow resume reads those records before asking again or generating duplicates.

Use checkpoint labels `brief`, `look`, `motion`, `soul`, `voice`, `install`. Approvals cover a nonempty explicit file list and the real user's message; do not record an approval on the user's behalf. All required artifacts must exist and retain their hashes at install time. Any source change requires a refreshed preview/approval of the affected artifacts. 'Approve all' means all items actually shown in the current packet. Installation never begins just because generation was approved.
