# Task4 registered producer captures

Nine new scenarios, 69 exact registered exchanges, captured by the sole new SDK test
`tests/test_relay_phone_history_task4_capture.py` using the current production
registrations. See capture.py.txt, provenance.json and the owned evidence generation
`task4-capture-r1` for exact requests, original response strings/hashes, source/import
pins, canonical command, XML and phases. Session JSON is copied byte-for-byte.

Integrated covers real sanitized title, bookmark, authorized query/filter and a
withheld socket response followed by the same immutable request ID/body/revision.
Other scenarios cover denial, expiry, current method withdrawal, retired,
superseded, stale revision, human-text query and unavailable route. Actual grants,
admission and SQLite are used; pairing, socket, clock and provider are synthetic.
No TLS/TCP/device/live/billing acceptance follows. Existing recordings and server
production are unchanged. Two module resource copies support actual protocol replay
and mobile production-owner integration tests, not two producer executions.
