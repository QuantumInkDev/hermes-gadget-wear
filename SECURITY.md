# Security

Please report security problems privately. Use GitHub's
[private vulnerability reporting](https://github.com/QuantumInkDev/hermes-gadget-wear/security/advisories/new)
for this repository, not a public issue.

Include what you found, how to reproduce it, and which app version (phone, watch or server
plugin) it affects. Don't include your real endpoints, keys or pairing codes. Placeholders are
fine.

In scope: the phone and watch apps, the relay protocol, the server patches and the catalog
publisher in this repository. Problems in Hermes Agent itself or in the upstream Gadget plugin
belong to those projects.

During the beta, fixes ship in the next beta build. Supported version: the latest beta.
