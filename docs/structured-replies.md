# Reply cards

Quantum Relay can show code, HTTPS links, explicit addresses and checklists as cards
inside an agent's response. Other text remains readable, including unrecognized markup.
Choose **Full text** to read the original response or **Copy full response** to copy it.

On the phone, cards show their detail directly. On the watch, choose **Expand** on a
card to see its detail. The portrait stays clear, and **Jump to profile** remains at the
end of the page.

- **Copy code** copies the code with its original spacing and line breaks. It does not run it.
- **Open link** shows the HTTPS host and opens an app chooser after a deliberate tap.
- **Open address** sends the displayed address to an app chooser. If no app can handle it,
  the response remains available to read or copy.
- Checklist changes stay on the current response screen. Switching between cards and full
  text keeps them; a new reply, profile or connection clears them. Checking an item does
  not change a remote task or approve an agent action.

Reply actions pause while a response is changing, a turn is busy, an approval is pending
or the connection is unavailable. The watch currently reports **Open on phone** as
unavailable; it does not send the response to another profile.
