# Phone messaging: native evidence

[Native gallery](index.html) · [Original capture manifest](manifest.json) ·
[Review and corrections](../../phone-messaging-review.md)

The approved Courier character, compact composer, actual-level waveform presentation,
full-name header and shared picture sheet are implemented in native Compose. These raw
PNG exports use synthetic profiles and original fixture portraits. No personal phone
window, endpoint, key or artwork is included.

The gallery includes Light, Dark and Electronic Moonlight, typed messages above the IME,
reply playback, recording, the directory and both picture entry points. Separate windows
cover 320×640 dp at font 1.8, 360×720 dp at font 1.3 and 640×320 dp at font 1.3.
The native system/round/squircle/themed icon capture resolves the packaged resource layers.
The manifest binds each unretouched PNG to source, APK/test-APK SHA, dimensions and scenario.

Recording layout fixtures feed synthetic amplitudes through the same bounded-history
renderer. Actual capture/playback, independent identities, permission completion and TLS
are exercised separately against isolated stock Gadget servers. Layout screenshots do
not establish physical microphone quality, spoken-voice comfort or away connectivity.

Demo: open a bot's Talk/Chat screen. Hold the inline microphone, watch the timer/level
stream, release to send, or slide physically left to cancel. Short taps discard. Accessible
Start, Finish and Cancel work without holding. Typing replaces the mic with Send. From a
profile's options, Watch picture opens a sheet whose Cancel footer stays separate from
the scrolling actions. Settings and Your profiles remain subordinate to the full title.

The owner's physical update preserves identities, art, configuration and timeout; it does
not launch or capture the phone. Physical speech/gesture comfort and the existing release
gates remain separate owner observations. The watch's installed build is unchanged.
