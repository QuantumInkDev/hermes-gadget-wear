# Phone messaging icon concepts

These are proposed original replacement icons, not installed launcher assets.

- `courier-concept.png`: original generated courier mascot; no reference image was used.
  Source composition is a concept. Adaptive-safe foreground/background separation and
  a dedicated monochrome silhouette must be completed after selection.
- `winged-relay-concept.svg`: original deterministic geometric winged messenger emblem.

Both are independent project artwork. No personal profile art or upstream mascot is included.
