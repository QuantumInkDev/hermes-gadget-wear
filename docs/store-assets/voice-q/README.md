# Voice Q

Original geometric Q/dialogue/orbit mark for Quantum Relay for Hermes. SVG masters and
checksums are listed in [manifest.json](manifest.json); Android vector foreground/background,
monochrome layers and launcher densities are generated assets in the native clients.

[Native screenshots](../../demo/native-clients/README.md) show the implemented identity with
synthetic data. These files contain no Nous mascot or personal pet art. Publication naming,
trademark review, feature graphic, final store screenshot selection and Play prerequisites
remain in [release preparation](../../release.md).
